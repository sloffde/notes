# SLOFFDE 学习笔记站（notes）

MkDocs Material 构建的本科医学生笔记站点，属 SLOFFDE 项目。

- 线上：<https://sloffde.github.io/notes/>
- 构建工具：[MkDocs Material](https://squidfunk.github.io/mkdocs-material/)（MIT）

## 本地预览

```bash
pip install mkdocs-material
mkdocs serve          # http://127.0.0.1:8000
```
