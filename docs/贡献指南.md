# 贡献指南

欢迎为 SLOFFDE 贡献学习资料！两个站点的贡献方式一致：

1. **开 Issue（零基础）**：在对应仓库提 Issue，贴上题目或笔记内容，维护者代为整理。
2. **网页端编辑**：在 GitHub 仓库进入对应 `.md`，点 ✎ 直接编辑提交。
3. **Pull Request（标准）**：fork → 改 → PR。

具体格式规范与脱敏要求，见各仓库根目录的 `CONTRIBUTING.md`：

- 历年题站：[pastpapers/CONTRIBUTING.md](https://github.com/sloffde/pastpapers/blob/main/CONTRIBUTING.md)
- 学习笔记站：[notes/CONTRIBUTING.md](https://github.com/sloffde/notes/blob/main/CONTRIBUTING.md)

> 所有贡献均须遵守 [医学免责声明](./disclaimer.md) 与脱敏要求。
